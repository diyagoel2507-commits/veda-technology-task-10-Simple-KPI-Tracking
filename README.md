# Simple KPI Tracking Sheet

## Project Overview

This project was completed as part of the VEDA Technology Data Analytics Track.

The main objective of this task was to create a simple and dynamic KPI tracking sheet using the Sample Superstore Dataset in Microsoft Excel.

The sheet tracks important business metrics using Excel formulas and a structured data table.

## KPIs Tracked

- Total Revenue
- Total Units Sold
- Total Orders
- Average Order Value
- Top Product

## Tools Used

- Microsoft Excel
- Sample Superstore Dataset
- Excel Tables
- Excel Formulas
- Structured References

## Key Results

| KPI | Value |
|---|---:|
| Total Revenue | ₹95,173.09 |
| Total Units Sold | 2,361 |
| Total Orders | 600 |
| Average Order Value | ₹158.62 |
| Top Product | Copiers Product 26 |

## Dynamic KPI Tracking

The raw data was converted into an Excel Table named `Orders`.

The KPI formulas use structured references, so the values automatically update when new records are added to the table.

The dynamic functionality was tested successfully by adding a new record and verifying that the KPI values updated automatically.
